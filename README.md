# UniTransfer

Aynı Wi‑Fi ağındaki cihazlar arasında internetsiz, hesapsız, kablosuz dosya aktarımı.

iPhone, iPad, Android, Windows ve Mac arasında fotoğraf, video, dosya ve klasör gönderin. Dosyalar doğrudan cihazdan cihaza gider; buluta yüklenmez.

## Özellikler
- **Otomatik keşif:** Aynı ağdaki UniTransfer çalışan cihazlar listede kendiliğinden görünür.
- **Her şeyi gönderin:** Fotoğraf, video, belge ve klasörler (klasör yapısı korunur).
- **Platformlar arası:** iPhone, iPad, Android, Windows ve Mac.
- **Galeriye kaydet:** Gelen fotoğraf ve videolar isteğe bağlı olarak Fotoğraflar'a eklenir.
- **Gizli:** Veri toplanmaz, sunucu yok, reklam yok.
- **Elle bağlantı:** Cihaz görünmüyorsa IP adresiyle eklenebilir.

# UniTransfer (English)

Wireless file transfer between devices on the same Wi‑Fi network — no internet, no account, no cables. Send photos, videos, files and folders between iPhone, iPad, Android, Windows and Mac. Files go directly from device to device and are never uploaded to a cloud.
